# Glosario v0.1 — BiblioSmart

| Término | Significado inicial |
|---|---|
| Título bibliográfico | Obra registrada en el catálogo de la biblioteca, independiente de la cantidad de copias físicas existentes. |
| Ejemplar | Copia física individual de un título bibliográfico, identificada mediante un código único y con un estado que determina su disponibilidad. |
| Catálogo | Conjunto de títulos bibliográficos registrados y disponibles para consulta dentro del sistema. |
| Autor | Persona asociada a la autoría de uno o más títulos bibliográficos. |
| Editorial | Entidad responsable de la publicación de uno o más títulos bibliográficos. |
| Usuario | Persona registrada en el sistema cuya interacción depende de los permisos y responsabilidades de su rol. |
| Rol | Conjunto de permisos y responsabilidades asignados a un usuario dentro del sistema. |
| Lector | Usuario que consulta el catálogo, realiza reservas permitidas y revisa sus préstamos. |
| Disponibilidad | Información que indica si un título cuenta con ejemplares que pueden prestarse; debe derivarse del estado real de los ejemplares. |
| Préstamo | Registro mediante el cual un ejemplar es entregado a un lector durante un periodo determinado, con fecha de salida y fecha prevista de devolución. |
| Devolución | Operación que finaliza un préstamo y actualiza el estado del ejemplar; normalmente lo deja disponible, salvo que exista una reserva prioritaria. |
| Renovación | Extensión del plazo de un préstamo vigente, permitida únicamente cuando las reglas del sistema lo autorizan y el ejemplar no está reservado por otro lector. |
| Reserva | Solicitud registrada por un lector sobre un título bibliográfico para obtener prioridad de acceso a un ejemplar cuando corresponda. |
| Prioridad de reserva | Orden utilizado por el sistema para determinar qué lector debe ser atendido primero cuando un ejemplar pueda asignarse a una reserva. |
| Sanción | Restricción operativa aplicada a un lector; mientras esté activa impide que realice nuevos préstamos. |
| Mora | Situación en la que un préstamo supera su fecha prevista de devolución sin que el ejemplar haya sido devuelto. |
| Auditoría | Registro de operaciones críticas que permite conservar trazabilidad sobre acciones relevantes realizadas en el sistema. |

> Este glosario es v0.1. Los significados pueden refinarse cuando aparezcan nuevas reglas o decisiones, pero los cambios deberán quedar documentados.
