# Backlog v0.1 — BiblioSmart

## Convención de prioridad

- P0: imprescindible para el flujo crítico del MVP.
- P1: importante para completar la operación.
- P2: complemento posterior.

### BS-001 — Gestionar usuarios y roles
**Prioridad:** P0

Como administrador, quiero gestionar usuarios y sus roles para que cada persona pueda interactuar con el sistema según sus responsabilidades.

### BS-002 — Registrar autores y editoriales
**Prioridad:** P1

Como bibliotecario, quiero registrar autores y editoriales para asociarlos correctamente con los títulos bibliográficos del catálogo.

### BS-003 — Registrar título bibliográfico
**Prioridad:** P0

Como bibliotecario, quiero registrar un título bibliográfico para incorporarlo al catálogo y permitir que los lectores puedan consultarlo.

### BS-004 — Registrar ejemplares de un título
**Prioridad:** P0

Como bibliotecario, quiero registrar los ejemplares físicos de un título con código único para controlar cada copia de manera individual.

### BS-005 — Consultar catálogo y disponibilidad
**Prioridad:** P0

Como lector, quiero buscar títulos y consultar su disponibilidad para saber si existen ejemplares que puedan prestarse o si necesito realizar una reserva.

### BS-006 — Crear reserva
**Prioridad:** P0

Como lector, quiero reservar un título para obtener prioridad cuando corresponda la asignación de un ejemplar.

### BS-007 — Registrar préstamo
**Prioridad:** P0

Como bibliotecario, quiero registrar el préstamo de un ejemplar a un lector para dejar constancia de quién tiene la copia y hasta cuándo debe devolverla.

### BS-008 — Consultar mis préstamos y vencimientos
**Prioridad:** P0

Como lector, quiero consultar mis préstamos y sus fechas previstas de devolución para conocer mi situación y cumplir con los plazos establecidos.

### BS-009 — Registrar devolución
**Prioridad:** P0

Como bibliotecario, quiero registrar la devolución de un ejemplar para cerrar el préstamo y permitir que el sistema actualice su disponibilidad o atienda una reserva prioritaria.

### BS-010 — Renovar préstamo
**Prioridad:** P1

Como lector, quiero renovar un préstamo vigente para extender su plazo cuando las reglas del sistema lo permitan.

### BS-011 — Gestionar prioridad y vencimiento de reservas
**Prioridad:** P1

Como bibliotecario, quiero gestionar la prioridad y el vencimiento de las reservas para que los ejemplares liberados puedan asignarse de forma coherente y las reservas vencidas no bloqueen la operación.

### BS-012 — Consultar mora y sanciones
**Prioridad:** P1

Como supervisor, quiero consultar la mora y las sanciones activas para conocer el nivel de cumplimiento de los lectores.

### BS-013 — Consultar historial personal
**Prioridad:** P1

Como lector, quiero consultar mi historial de préstamos para revisar las operaciones que he realizado en la biblioteca.

### BS-014 — Consultar dashboard operativo
**Prioridad:** P1

Como supervisor, quiero consultar un dashboard de préstamos, mora y disponibilidad para entender el estado operativo de la biblioteca.

### BS-015 — Configurar parámetros operativos
**Prioridad:** P1

Como administrador, quiero configurar parámetros como el plazo de retiro de una reserva y el máximo de préstamos simultáneos para adaptar el funcionamiento del sistema a las políticas de la biblioteca.
