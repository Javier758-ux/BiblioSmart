Decisiones técnicas y de producto

Esta carpeta almacenará las decisiones relevantes del proyecto BiblioSmart, ya sean decisiones técnicas, arquitectónicas o de producto.

Cada decisión importante deberá indicar:

Contexto.
Problema o decisión a resolver.
Alternativas consideradas.
Decisión tomada.
Consecuencias conocidas.

En la Clase 01 todavía no se registra una decisión arquitectónica formal, ya que aún no se ha iniciado el diseño técnico detallado del sistema.

Las decisiones que se documenten posteriormente deberán ser coherentes con la ficha oficial de BiblioSmart, el alcance definido para el proyecto y las tecnologías establecidas para la asignatura.
